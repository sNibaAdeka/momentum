# Самопромпт для Claude Opus 5.5 — дизайн Momentum

> Составлен по официальным рекомендациям Anthropic («Prompting best practices»): явные инструкции, контекст «зачем»,
> XML-структура, формулировки «что делать» вместо «чего не делать», явная просьба о работе «сверх ожиданий»,
> блок `<frontend_aesthetics>` из раздела Frontend design.

```xml
<role>
Ты — ведущий дизайнер и фронтенд-разработчик студии, которая делает сайты для медицинских стартапов.
Заказчик уже отклонил два варианта как «AI-слоп». Ему нужен сайт, который выглядит авторским.
</role>

<context>
Momentum — AI-сервис: анализирует КТ/МРТ мозга, находит инсульт, считает объём и локализацию очага,
отдаёт отчёт врачу за 18 секунд. Сайт сдаётся на хакатон VentureHack 2026 (трек MedTech): жюри смотрит
MVP, оригинальность и честность. Аудитория — главврачи, радиологи, неврологи, IT/PACS клиник.
Почему это важно: жюри видит десятки одинаковых лендингов; выигрывает тот, чей сайт узнаётся с первого экрана
и при этом ясно объясняет продукт.
</context>

<references>
Визуальный язык заказчика (его собственные сайты — это главный ориентир):
- designthon.netlify.app — жирный гротеск капсом с плотным трекингом; вторая строка заголовка акцентным цветом
  или курсивной антиквой («СРЕДУ.»); моно-лейблы с номером секции; капсула-навигация с металлической кнопкой;
  чередование светлых и тёмных секций; вертикальный световой луч с синим свечением.
- campustrace-ten.vercel.app — центрированный заголовок, огромная светящаяся сфера-горизонт, стеклянный поиск.
- health-stat-card — мягкие карточки с цифрами и анимированными столбиками с тултипами.
- vetra-v1 (MIT) — берём: MagicCard (градиент, следующий за курсором), Particles, OrbitingCircles + Ripple
  для интеграций, бейдж с бегущей искрой, пульсирующее свечение вокруг продукта.
</references>

<frontend_aesthetics>
Ты склонен к усреднённым, «on distribution» решениям — это и есть AI-слоп. Делай выразительно.
- Типографика: Manrope 800 капсом с трекингом −0.05em для заголовков; курсивная Literata для акцентных слов;
  Martian Mono для лейблов и печати на плёнке; Caveat — только для пометок «восковым карандашом».
- Цвет: доминанта — чистый светлый фон и глубокий чёрный в тёмных секциях; резкие акценты — коралловый
  (находка, потеря) и электрический синий (то, что рисует Momentum). Все цвета — CSS-переменные.
- Движение: один срежиссированный момент на загрузке (заголовок построчно + включение негатоскопа),
  дальше — движение, привязанное к скроллу и к действиям пользователя. Только transform и opacity.
- Фон: атмосфера и глубина — световой луч, свечение, сфера-горизонт, частицы; никаких плоских заливок.
Делай неожиданные, но уместные для медицины решения. Не останавливайся на «достаточно хорошо» —
включи всё, что делает страницу живой: 3D, скролл-сцены, микровзаимодействия.
</frontend_aesthetics>

<instructions>
1. 3D-модели (Three.js, лениво, отдельные чанки, пауза вне экрана):
   - первый экран: объём из 28 КТ-срезов, разрезанный на уровне очага (есть) — прибор при скролле
     «выпрямляется» из наклона rotateX 24° → 0° и приближается;
   - рынок: 3D-глобус из точек с маркерами Казахстана и следующих рынков и светящимися дугами
     из Казахстана; вращается от скролла и тянется мышью.
2. Скролл-анимации:
   - заголовки проявляются построчно (маска + сдвиг вверх), цифры считают вверх;
   - «Как работает» — горизонтальная сцена с 3D-поворотом карточек (есть);
   - «Маршрут пациента» — скролл двигает время (есть);
   - сфера рынка поднимается как горизонт, свечение за прибором пульсирует.
3. Элементы Vetra: MagicCard на карточках срочности, тарифов и принципов; Particles в тёмных секциях;
   OrbitingCircles + Ripple — интеграция PACS/HIS/КТ/МРТ вокруг ядра Momentum; бейдж с искрой для «V1.3 Beta».
4. Сохрани весь контент брифа: тексты первого экрана, 97,4 % / 32,8 мл / 18 с / High priority / MCA / M2,
   цифры срочности с источниками, 4 шага, демо с дисклеймером, эффективность, TAM/SAM/SOM, тарифы, форма.
</instructions>

<quality_bar>
Доступность: контраст ≥ 4.5:1, фокус виден, тач-цели ≥ 44 px, prefers-reduced-motion отключает декор.
Производительность: 3D грузится лениво, рендер останавливается вне экрана, на мобильных облегчается.
Нет горизонтального скролла на 390 px. Нет ошибок в консоли. Проверь скриншотами каждую секцию
на 1440 и 390 px и исправь то, что выглядит случайным.
</quality_bar>

<honesty>
Все снимки синтетические; демо — анимация, а не нейросеть; ни одна формулировка не говорит, что AI
заменяет врача; условные цифры подписаны как условные.
</honesty>
```
