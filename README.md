# Momentum — AI stroke detection · landing + interactive demo

**VentureHack 2026 · Трек 1 — MedTech и здоровье человека**

**Сайт:** https://momentum-kz.vercel.app · **Презентация:** https://canva.link/0o02ffb1p66fh98

Momentum анализирует КТ и МРТ головного мозга, находит признаки инсульта, определяет тип, объём и локализацию очага
и формирует отчёт для врача за ~18 секунд — пока пациент ещё в аппарате.

## Рабочая станция (демо)

- **Открытие исследований:** несжатый DICOM (несколько файлов, папка или ZIP; серия сортируется по ImagePositionPatient,
  ориентация приводится к радиологической), NIfTI `.nii` / `.nii.gz` (по аффинной матрице). Всё читается в браузере,
  файлы никуда не отправляются; имя, ID и дата рождения пациента не считываются.
- **Просмотр:** окна Мозг / Инсульт / Кость / Авто, листание (ползунок, колесо, стрелки), плотность HU под курсором,
  линейка в миллиметрах, разметка очагов и карта асимметрии.
- **Анализ** (`src/ct/analyze.ts`) — экспериментальный объяснимый алгоритм, не нейросеть:
  1. череп (HU ≥ 250) и внутричерепное пространство (заливка воздуха снаружи);
  2. срединная линия — длинная ось внутричерепной маски (вторые моменты);
  3. ткань мозга 15–60 HU, сглаживание ~3 мм только по ткани;
  4. сравнение каждой точки с зеркальной: гиподенсивная зона (на ≥ 5 HU темнее и ≤ 30 HU — похоже на ишемию),
     гиперденсивная (50–95 HU и на ≥ 12 HU плотнее — нужно исключить кровоизлияние);
  5. сборка островков соседних срезов в 3D, объём в мл по размеру вокселя, сторона, бассейн, приоритет.
- **Отчёт** из фактических результатов: печать, TXT, JSON. **История** — последние 6 анализов в `localStorage` (только сводка).
- **Пример файла:** `public/samples/momentum-sample-dicom.zip` — синтетическая серия с очагом *слева* (зеркально встроенной
  демо-серии), чтобы проверить загрузку. Генерируется `scripts/make-samples.ts`.
- Проверка на синтетике: объём 23,7 мл при эталонной маске 34,3 мл (Dice 0,80), здоровый симметричный объём — без находок,
  зеркальный — та же находка с другой стороны, добавленное «кровоизлияние» 68 HU находится. Расчёт 28 срезов — ~0,3 с.

## Честно о демо

- Все снимки на сайте **синтетические**: `src/ct/ctSynth.ts` генерирует КТ в единицах Хаунсфилда из шума и анатомических функций.
- Анализ в демо — настоящий расчёт, но это **простой алгоритм асимметрии плотности, а не обученная модель** Momentum.
  Он не валидирован на клинических данных и не является медицинским изделием. Цифры первого экрана (97,4 %, 32,8 мл, 18 с) —
  референсный кейс продукта из презентации.
- Momentum — инструмент поддержки решений и не заменяет врача.

## Стек

React 19 · TypeScript (strict) · Vite 6 · Three.js · Framer Motion 12 · React Hook Form + Zod · Lucide ·
dicom-parser · nifti-reader-js · fflate.
Без UI-китов: собственная дизайн-система на CSS-токенах (`src/styles/tokens.css`).

## Архитектура

```
src/
  ct/ctSynth.ts        синтетическая КТ (HU, маска очага, окна W/L)
  ct/volume.ts         объём исследования, окна, отрисовка с разметкой
  ct/loaders.ts        DICOM / ZIP / NIfTI → объём (dicom-parser, fflate, nifti-reader-js)
  ct/analyze.ts        алгоритм асимметрии плотности
  ct/describe.ts       формулировки находок и рекомендаций
  ct/cache.ts          кэш срезов, PNG-превью
  three/StackScene.ts  3D-объём из срезов (ленивая загрузка, graceful fallback без WebGL)
  sections/            секции страницы; demo/ — просмотрщик и отчёт
  components/          навигация, скаут-рейл, примитивы (магнитные кнопки, reveal, счётчики)
  lib/                 часы нейронов, форматирование, env/motion-токены
```

- 3D грузится лениво (`import()` после первой отрисовки), на мобильных — облегчённый режим, без WebGL — статичный срез.
- `prefers-reduced-motion` уважается везде.
- Доступность: семантические секции, skip-link, фокус-стили, aria-метки, клавиатурное управление просмотрщиком.

## Запуск

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/ — для хостинга
npm run build:single   # dist-single/index.html — один файл, открывается без сервера
```

Форма: задайте `VITE_DEMO_ENDPOINT` (POST JSON) или `VITE_NETLIFY_FORMS=1` (Netlify Forms). Без них — режим предпросмотра.
