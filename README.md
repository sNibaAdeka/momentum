# Momentum — AI stroke detection · landing + interactive demo

**VentureHack 2026 · Трек 1 — MedTech и здоровье человека**

Momentum анализирует КТ и МРТ головного мозга, находит признаки инсульта, определяет тип, объём и локализацию очага
и формирует отчёт для врача за ~18 секунд — пока пациент ещё в аппарате.

## Что внутри

| Раздел | Что показывает |
| --- | --- |
| Первый экран | 3D-объём из 28 КТ-срезов (Three.js): голова «сканируется» срез за срезом, очаг проявляется коралловым объёмом |
| Счётчик в шапке | Сколько нейронов потерял бы пациент без лечения, пока открыта страница (1,9 млн/мин, Saver 2006) |
| Маршрут пациента | Скролл = время: обычный маршрут против маршрута с Momentum (модельный пример) |
| Как работает | 4 этапа pipeline с 3D-переходами |
| Демо | Мини-PACS: загрузка файла, анимация анализа, маска, окна W/L, HU под курсором, отчёт с печатью |
| Эффект · Рынок · Тарифы | 5×, $100k, 24/7, PACS/HIS, ROI-калькулятор, TAM/SAM/SOM, Core $199 / Clinic+ $399 |
| Форма | Запрос демо (React Hook Form + Zod) |

## Честно о демо

- Все снимки на сайте **синтетические**: `src/ct/ctSynth.ts` генерирует КТ в единицах Хаунсфилда из шума и анатомических функций. Реальных данных пациентов нет.
- Анализ в демо — **анимация на заранее размеченном синтетическом исследовании**, а не работа нейросети. Показатели (97,4 %, 32,8 мл, 18 с) — референсный кейс продукта.
- Загруженный пользователем файл не отправляется на сервер и не анализируется.
- Momentum — инструмент поддержки решений и не заменяет врача.

## Стек

React 19 · TypeScript (strict) · Vite 6 · Three.js · Framer Motion 12 · React Hook Form + Zod · Lucide.
Без UI-китов: собственная дизайн-система на CSS-токенах (`src/styles/tokens.css`).

## Архитектура

```
src/
  ct/ctSynth.ts        синтетическая КТ (HU, маска очага, окна W/L)
  ct/cache.ts          кэш срезов, PNG-превью
  three/StackScene.ts  3D-объём из срезов (ленивая загрузка, graceful fallback без WebGL)
  sections/            секции страницы; demo/ — просмотрщик и отчёт
  components/          навигация, скаут-рейл, примитивы (магнитные кнопки, reveal, счётчики)
  lib/                 часы нейронов, форматирование, env/motion-токены
```

- 3D грузится лениво (`import()` после первой отрисовки), на мобильных — облегчённый режим, без WebGL — статичный срез.
- `prefers-reduced-motion` уважается везде.
- Доступность: семантические секции, skip-link, фокус-стили, aria-метки, клавиатурное управление просмотрщиком.

## Запуск

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/ — для хостинга
npm run build:single   # dist-single/index.html — один файл, открывается без сервера
```

Форма: задайте `VITE_DEMO_ENDPOINT` (POST JSON) или `VITE_NETLIFY_FORMS=1` (Netlify Forms). Без них — режим предпросмотра.
